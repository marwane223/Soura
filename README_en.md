# Quran Surahs — Revival and Improvements

This website revives the original **Soura** site, which is no longer available. It is based on the original project created by [Emad Adel](https://github.com/emadadeldev/Soura), with proper attribution to its creator.

## About this version

The project has been republished and improved with the following features:

- Choose a reciter from the list.
- Search for reciters.
- Save the selected reciter and playback position to restore them after refreshing the page.
